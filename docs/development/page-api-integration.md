真实连接模式会发送请求并显示接口错误，不会用演示数据代替真实记录，也不会显示虚假的操作成功。

## 前端连接方式

接口文件按业务模块放在 frontend/src/api 下，便于分工维护。共用请求层携带若依登录令牌、保留服务器错误、提示缺少接口、添加写入请求标识，并在登录会话变化后拒绝使用旧响应。

页面操作等待服务器返回，再重新读取受影响的案例状态。直接打开案例详情会请求数据，不再要求内存里已有这个案例。进度页定期读取服务器状态，真实连接模式不会运行前端模拟流程。

目前支持的响应格式：

- 若依普通响应：`{ code, msg, data }`。
- 若依分页响应：`{ code, rows, total }`。
- 已有业务响应：`{ code, message, data }`。

拟定的业务列表接口目前要求返回数组。详情字段需要与已有页面使用的字段对应。本次没有补造缺少的分数，也没有把简历当成岗位模拟案例。

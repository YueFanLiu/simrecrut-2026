# 页面按钮接入与真实简历测试报告

日期：2026-10-12。测试环境：本机前端 5173、Java 后端 8080，已登录管理员，真实连接模式。

## 当前结论

现有按钮的页面跳转、请求入口和本地交互已检查并接入；这不表示全部业务后端已实现。简历上传、识别、校对、保存、确认和云端发布能够运行。岗位、案例评分、研究实验、审核任务等仍被缺少的业务接口阻断，不能完成端到端业务。没有用演示数据代替真实接口成功。

本次未修改原页面布局、样式或补做缺少的 UI，未提交或推送 Git。代码注释仍使用英语。

## 按钮和导航检查

Vue 模板检查覆盖 views 和 layouts 中 266 个按钮及路由链接，包括尚未用于当前路由的旧组件。已核对点击处理、路由目标、表单提交及明确禁用的控件；发现的命名路由引用均有对应定义。这个检查只能证明绑定存在，不能证明后端业务成功。

本次修正：

- 状态页退出登录等待若依退出请求完成。
- 研究指标入口使用当前或已加载的实验 ID，移除固定演示实验 ID。
- 研究页面只请求本页需要的数据；异步数据到达后再恢复对象选择和模型预选。
- 角色分配页加载真实用户；分配请求成功后刷新用户和角色。
- 模型注册选项改从服务端模型包目录获取，真实模式不再提供虚构演示包；活动版本从服务端状态恢复。
- 简历和案例识别重试捕获失败，避免未处理的错误。

## 页面实际测试结果

| 输入/操作 | 结果 | 限制或发现 |
| --- | --- | --- |
| A：2 页文本 PDF，约 152 KB | 上传→识别→人工补学历→保存→刷新确认补充仍在→确认→发布成功 | 自动得到技能 9、经历 2、学历 0、语言 0、项目 1。原文有学历，存在漏识别。人工学历来源保存为 USER_SUPPLIED |
| B：2 页文本 PDF，约 92 KB | 上传→查看五组事实→保存→确认→发布成功 | 自动得到技能 3、经历 1、学历 2、语言 0、项目 0。数量不是准确率，也不保证所有条目识别齐全 |
| 派生扫描 PDF，约 548 KB | 页面提示第 1、2 页使用本地 OCR；保存、确认、发布成功 | 计数与 A 相同，学历仍漏识别。该测试验证技术流程，未证明内容完整或人工标注准确 |
| 20 页派生 PDF | 上传及提取成功，进入五组事实校对 | 保留未确认，不发布边界测试事实；没有用它评价识别准确率 |
| 21 页 PDF | 拒绝 | 提示只能包含 1–20 页 |
| 加密 PDF | 拒绝 | 提示文件无效或受密码保护 |
| 损坏 PDF | 拒绝 | 同上，无正常事实校对流程 |
| 超过 10 MB PDF | 拒绝 | 提示文件大小限制 |
| 空白 PDF | 上传后识别失败；重试按钮能发起再次提取 | 明确提示没有可用文本；没有确认或发布空白事实 |
| 错误 JSON 草稿（输入一个左方括号） | 保存被阻止 | 页面提示未保存，没有假成功 |
| 重复上传已发布的 A | 返回同一简历 ID，仍显示 Facts published | 人工补充学历仍存在，未覆盖已确认的事实 |

三次发布最终均显示 Facts published，确认后不可继续保存草稿，并且没有临时原件清理重试按钮。此结论来自真实页面及页面对应的服务端状态；本次没有另行查询云对象内容。未实际等待 24 小时/30 天来验证到期删除。

本次新建了 5 条测试记录：3 条已发布，20 页与空白文件各 1 条未确认。记录留在管理员账号中便于复查，没有永久删除。无效的 4 份文件未进入正常简历流程。

## 仍缺少的 UI

这些只记录，不修改原页面：

1. 多个页面仍写着 Demo、synthetic 或前端演示说明，与真实连接模式不一致。
2. 简历校对仍直接编辑 JSON，缺少结构化字段编辑、缺项提示和原文证据对照。
3. 注册入口没有连接真实注册业务；账号恢复/修改密码也需要正式页面和流程。
4. 用户、角色和权限页面的业务字段需要和若依数据结构统一；不能只把若依接口地址替换进去。
5. 研究创建与审核分配中的部分选项仍为固定演示配置，缺真实协议、权重、审核人和权限约束的选项来源。
6. 首页已有模块入口，但没有真实业务统计首页；结果页缺真实运行结果，不能凭现有图形认定评估已实现。
7. 失败任务的安全重试确认流程和操作权限尚未提供。

## 仍缺少的业务

按可用流程的先后顺序：

1. 岗位草稿、要求和权重、版本校验、发布及公开列表服务。
2. 把已保存简历与岗位版本绑定为案例；案例权限、校对版本、运行队列、状态和结果存储。
3. Objective、Neutral、Biased 三种真实评估，以及可解释结果和模型调用；当前没有由页面请求驱动的完整评估链。
4. 人工审核任务的真实分配、匿名事实、提交、锁定及结果回写。
5. 研究对象授权、变体生成、实验执行、配对结果和公平性指标。
6. 模型包目录、登记/审批/激活/替换、冻结协议、安全服务健康和失败任务操作。
7. 若依账号与业务角色/权限适配，以及业务审计代码与资源信息。
8. 简历识别词典、跨行布局和日期/学历/项目规则的完善；需要有人工标注的测试集验证准确率。两份真实样本不足以给出可靠准确率。
9. 自动过期删除、云端故障补偿、多人同时修改和普通账号越权的完整实测。本次没有通过改权限或故意破坏环境来测试。

拟定请求路径和后端字段要求见[页面接口接入说明](page-api-integration.md)。这些拟定路径不是已实现的服务。
